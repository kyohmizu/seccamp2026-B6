# 第3章 Google Cloud 環境での演習

架空の企業 PayLoad が開発・運用するサービス「FlowPay」を題材とし、CI/CD パイプラインにおけるソフトウェアサプライチェーンセキュリティ対策の実装手法を学びます。対策導入前の初期状態に対し、モジュール化された演習を通して段階的にセキュリティを堅牢化していきます。

## 構成
- `exercises/` — モジュール形式の演習コンテンツ。各演習ディレクトリに README（課題定義）・検証手順・解答例（`solutions/`）が格納されています。

演習で扱う FlowPay 環境の実装コードは、リポジトリ直下の [`../src/`](../src/) に配置されています。全章で共通して使用するリソースのうち、演習で対象となる主要な構成要素は以下の3つです。

- `../src/backend/` — Go 言語で実装された経費精算 API。非公開（private）設定の Cloud Run サービスとして動作し、frontend からのアクセスのみを許可します。
- `../src/frontend/` — Node.js / Express で構築された Web UI アプリケーション。金額の整形処理は外部 OSS パッケージ `expense-format` に依存しており、演習用のプライベート npm レジストリから取得します。
- `../src/pipelines/` — Cloud Build のパイプライン定義ファイル（ビルド / PR チェック / デプロイ）。

実際の演習作業では、本 FlowPay 環境から生成された個別の演習用リポジトリを使用して作業を進めます（`backend/`・`frontend/`・`cloudbuild.yaml` がリポジトリ直下に配置された構成となります）。
