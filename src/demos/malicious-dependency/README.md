# 悪性依存パッケージ攻撃デモ資材

frontend サービスが直接依存する金額整形ライブラリ `expense-format` を題材とし、依存関係の更新処理に乗じて公開直後の悪性バージョンを取り込ませる OSS サプライチェーン攻撃の手法を、実際のパイプライン環境（GitHub → Cloud Build → Cloud Run）およびローカル環境で再現するための実装コード一式です。

> 悪意あるコードの挙動は安全性を担保したシミュレーションプログラムとして設計されています（実際に悪用可能な資格情報の収集や機密データの外部流出処理は行いません）。**攻撃プロセスの詳細解説（安全前提・攻撃シナリオ・実環境における実行フローと結果）については、講義資料 [../../../chapter1/attack-demo.md](../../../chapter1/attack-demo.md) を参照してください。**

## ディレクトリ構成
- `registry/` … デモ対象パッケージ `expense-format` のソースコード（実環境およびローカル環境の双方で共有）
  - `expense-format-good/` … 正規バージョン 1.0.0（`formatYen` 関数の正常実装のみを保持）
  - `expense-format-evil/` … 悪性バージョン 1.0.1（`formatYen` 関数の正常動作を維持しつつ、インストール時（`postinstall`）および実行時（関数呼び出し時）の両段階でデータ送信処理を実行）
- `gce/` … 実環境検証用ファイル一式（Compute Engine 上の Verdaccio＝公開 npm レジストリの代替、ファイアウォール設定、パブリッシュスクリプト、CI/CD パイプライン連携、攻撃者用 C2 サーバー（`gce/attacker/`）、プロビジョニング・クリーンアップ用スクリプト）。**環境構築手順およびデモ実行コマンドの詳細は [gce/README.md](gce/README.md) を参照してください。**
- `local/` … オフライン環境で自己完結するローカル検証用サンドボックス（Verdaccio ＋ モック C2 ＋ 被害アプリケーション）。**実行手順および各種出力結果の詳細は [local/README.md](local/README.md) を参照してください。**

> 被害対象アプリケーション本体は、本ディレクトリ外の `src/frontend/`（`expense-format@^1.0.0` に直接依存する Cloud Run サービス）に配置されています。
