# ソフトウェアサプライチェーンの構造的リスクとコンテナ環境の保護

[セキュリティ・キャンプ2026 全国大会](https://www.ipa.go.jp/jinzai/security-camp/2026/camp/zenkoku/index.html) B6 講義資料

※ 内容は随時更新される可能性があります。

## 概要

現代のソフトウェア開発は、OSS依存、CI/CD、コンテナ技術の上に成り立っています。これに伴い、ソフトウェアサプライチェーン全体を狙う攻撃は増加・高度化しています。単なる既知の脆弱性だけでなく、悪性コードの混入、メンテナアカウントの乗っ取り、CI/CD基盤の侵害といった、従来の境界防御を迂回する手法が主流となりつつあります。

本講義では、仮想企業 PayLoad の経費精算サービス「FlowPay」を題材として、ソフトウェアサプライチェーンのリスクを構造的に理解するとともに、Cloud Build や Cloud Run を中心とした Google Cloud 上の CI/CD パイプラインを保護する実践的な対策を学びます。

## 対象者・前提知識

- Git および GitHub を用いた基本的な開発フローを理解している方
- Docker やコンテナの基本概念を理解している方
- CI/CD による自動ビルド・デプロイの基礎知識を有する方
- Google Cloud をはじめとするクラウド基盤の基礎に関心がある方
- ソフトウェアサプライチェーンやコンテナセキュリティに関心がある方

## 学習目標

本講義では、以下の習得を目指します。

- ソフトウェアサプライチェーンの全体像と、開発段階および「人・プロセス・技術」の各軸におけるリスク構造の理解
- インシデント事例や実演に基づく、脆弱性と悪性コードの違い、および従来型防御の限界の説明
- 脅威モデリングによる攻撃面の洗い出しと、リスクに基づく優先順位付け
- SBOM、署名、provenance、検証などの中核技術と、SLSA や NIST SSDF などのフレームワークの位置づけの把握
- CI/CD パイプラインにおける依存関係の固定、ビルド用サービスアカウントの権限最小化、署名・provenance の付与、デプロイ時検証の実装

## 章構成

### [第1章 ソフトウェアサプライチェーンの構造的リスク](./chapter1)

Shai-Hulud、axios、TanStack などの実際のインシデント事例を参考に、Source から Runtime に至る開発ライフサイクルと「人・プロセス・技術」の 3 軸から攻撃構造を整理します。講義内では、悪意ある依存パッケージを用いた CI 侵害を FlowPay 環境で実演します。

### [第2章 脅威モデリングと対策](./chapter2)

PayLoad のアーキテクチャを対象に、脅威モデリングで攻撃経路を洗い出し、受講生同士のディスカッションを通じてリスクの優先順位を設定します。あわせて、主要な対策技術と SLSA、S2C2F、NIST SSDF などのセキュリティフレームワークを整理し、対策選定の指針を明確にします。

### [第3章 Google Cloud 環境での演習](./chapter3)

Google Cloud 上の FlowPay パイプラインを用いて、SCA/SBOM 解析、イメージの digest 固定、ビルド用サービスアカウントの権限最小化、イメージ署名と provenance の付与、Binary Authorization によるデプロイ時検証を実装します。未対策の環境から、モジュール形式の演習を通じて段階的に堅牢化を進めます。
